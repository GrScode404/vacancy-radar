Описание вакансии

Проект flexcard — сервис виртуальных банковских карт для оплаты рекламы и онлайн-сервисов. Мы создаём удобные и безопасные платёжные решения для рекламодателей, маркетинговых команд и бизнеса, которым нужны стабильные инструменты для закупки трафика и работы с международными площадками.

Основные обязанности:

    Разработка типовых задач на Python/Django под руководством фича-лида: CRUD-эндпоинты, формы, админ-панель, простые интеграции.

    Написание unit-тестов для нового кода (с постепенным ростом покрытия).

    Участие в code review (сначала как наблюдатель, затем — с правом комментирования).

    Исправление багов по трекеру, работа с логами и базовой диагностикой.

    Документирование своих изменений и участие в поддержке ЧАВО.

    Работа по процессам Scrum: ежедневные стендапы, планирование, ретроспективы.

Владение специфичными компьютерными программами:

    Python 3.x (уверенный уровень, понимание ООП, структур данных).

    Django (базовый уровень: модели, views, шаблоны, ORM, миграции).

    Git (базовые команды, работа с ветками).

    SQL (базовое понимание: SELECT, JOIN, индексы).

    Linux (базовые команды, работа в терминале).


Желательно: Docker (понимание, зачем нужен), FastAPI (базово), Postman/curl.

Знания, необходимые для выполнения данной работы:

    Основы Python и Django: ORM, миграции, маршрутизация, шаблоны.

    Понимание HTTP, REST, статус-кодов, JSON.

    Базовое понимание реляционных БД и SQL.

    Понимание Git-flow и процесса code review.

    Представление о тестировании (unit-тесты, pytest/unittest).

    Понимание, что такое CI/CD (на уровне «код должен проходить проверки»).

Навыки, необходимые для выполнения данной работы:

    Умение читать чужой код и следовать существующим паттернам.

    Способность задавать вопросы и не стесняться просить помощь.

    Базовые навыки отладки: чтение логов, использование print/pdb, понимание ошибок.

Мы предлагаем:

    Полостью удаленный формат работы либо офис/гибрид Москва/Вологда.

    Встречи и корпоративные мероприятия

    Окладная часть + KPI

    Возможность влиять на архитектуру и выбирать технологии.

    Работу в сильной команде, поддержку профессионального роста.

    Интересные задачи в быстрорастущем проекте.
